# lr-kallisto reproducibility repository
This repository constains code for reproducing results and figures for the manuscript "[Long-read sequencing transcriptome quantification with lr-kallisto](https://www.biorxiv.org/content/10.1101/2024.07.19.604364v1)" by Rebekah Loving et al., 2024. Additionally, we demonstrate the scalable processing of single-nuclei data from demultiplexing through quantification in processing 1 million reads [with colab](https://github.com/pachterlab/LSRRSRLFKOTWMWMP_2024/blob/main/lr_kallisto_example.ipynb).
